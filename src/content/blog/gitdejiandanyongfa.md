这段时间硬盘出了点问题。突然发现自己之前写的好多代码都在这个盘里。如果不备份一下代码，万一硬盘突然挂掉，我之前的努力就全都功亏一篑了。

于是我就开始寻找可以方便备份代码的方法，找了半天发现还是得用git。git优点是一个分布式的方案，免费，网上有很多可以用的仓库。缺点嘛，就是这玩意是老外开发的，没有中文版。用的时候经常报错。明明是一个很简单的错误，可是用英语一说就给人感觉很难。所以这也是我不太喜欢git的一方面。

于是我专门花了两天时间去研究git。我发现学会了之后真的很简单。下面是我的一些简单的记录。

首先使用git之前要先下载git软件，具体我就不展开讲了。 其次找一个代码托管平台，github,gitee,gitcode,coding等等。 我的代码并不是开源的。很多仓库都是私人用的，考虑到网速问题，我选择了coding。我选择coding的另外一个原因，是因为开发者生态很全面，居然有在线的ide，风格简直和vscode一摸一样，有些代码直接在线上就写了，非常方便。

以上这两步是准备工作，必须先做好。

然后你需要在线上先创建一个远程仓库。 然后打开硬盘的根目录，在地址栏输入cmd，就会弹出一个终端命令显示器，这个时候在里面输入：git clone < your remote repository url >.git 于是就把线上的仓库给同步到本地了。这种方式对于新手比较友好，不需要再在本地初始化仓库了。 然后将你的代码复制到本地仓库中去。在终端中输入命令：git add .，在输入git commit -m "更改描述",最后输入git push，等待数据上传完成，就全部搞定啦！就这么简单。



```bash
cmd # 在硬盘根目录中输入
git clone https://e.coding.net/yuzhiblue/test.git # 先将远程仓库克隆到本地，这种方式对于新手比较友好。需要事先在线上先创建好仓库，首次使用会让你输入账号和密码。
git add . # 将修改和删除的文件添加进来
git commit -m "请输入描述" # 提交到缓存中
git push # 将本地仓库推送到远程服务器
```
