亚财联生意贷是由亚联财小额贷款有限公司推出的一款针对小微企业主和个体工商户的纯线上小额贷款产品。其基本条件包括：申请人年龄介于22周岁至55周岁之间，持有有效的中华人民共和国居民身份证，且为主贷人的商户法人代表需要拥有营业执照超过12个月。

亚财联生意贷的额度范围为1,000元至200,000元（额度当日有效，无循环额度），利率通常在年化11-24%之间，还款方式为等额本息。该产品可支持提前还款，并且如果续贷还款期数超过1/2时，也可以进行续贷计息。

值得注意的是，亚财联生意贷对征信有明确的要求：非白户；两年内不能有“2”，即不能有连续两次逾期记录，无当前逾期，且信用状态正常；账户状态不能为关注、可疑、次级、损失；呆账、逾期、司法追偿、担保物不足、银行止付等情形都将导致贷款申请被拒。

此外，亚财联生意贷的申请方式非常便捷，可以通过APP申请、微信申请、官网咨询或电话申请等方式进行。纯线上申请，无需纸质资料，秒申、秒审核、秒签，审批通过后即可快速放款。

### 一、产品要素

  1. 授信额度：20万
  2. 年化利率：11-24%
  3. 借款周期：3-12期
  4. 还款方式：等额本金，前三期不支持提前还款

### 二、准入要求

1、个人要求

申请人年龄：22-55周岁

2、企业要求

  * 经营执照注册时间满12个月，经营状态为正常
  * 流水情况：后台自动读取，月均不少于2万

3、征信要求

  1. 非白户；
  2. 逾期情况：2年不能有“2”，无当前逾期，且状态正常
  3. 账户含以下状态作拒贷处理：关注、可疑、次级、损失；呆账、逾期、司法追偿、担保物不足、银行止付。
  4. 信用卡使用额度不超过80%，近一个月查询最好不超过6次

### 三、禁入行业

暂无

### 四、准入区域

全国

### 五、常见问题

1、申请流程中有哪些需要注意的地方？

（1）客户必须要有营业执照，经营满1年且为法人，才可引导其申请【生意贷 ( H5 ) 】。

（2）优先导出及授权好微信/支付宝流水账单，其中微信流水账单下载前会收取到解压码，到时在【微信/支付宝流水授权页面】需要填写验证码( 邮箱地址： ylc@uaryd.com )

（3）在关注公众号之前，填写正确真实的手机号和验证码(注意：该页面输入的手机号将于公众号生成的H5链接会进行绑定及匹配)

（4）必须还款到1/2时才可申请续贷。如未还款到1/2时就提交申请续贷，将会被拒。

2、什么是商户编号？

商户编号是商户在收单机构入网时，收单机构给每个商户的15位特定代码。每个商户的商户编号具有唯一性。

第三方数据公司可通过商户编号来对应获取客户的流水数据。流水数据可帮助我司从客户每月的交易流水情况了解其经营情况，从而考察其还款能力，使我司更全面的了解客户的情况。

3、如何获取商户编号？

（1）通过POS机小票确定： 打印pos小票，小票上最上方写有“商户编号”且为15位数字的号码。

（2）通过电话咨询： 打电话咨询收单机构客服，查询商户编号 ( 收单机构指的是出售POS机的第三方支付公司 ) 。

（3）通过查看入网协议： 商户入网时会签署入网协议，其上会写明商户编号。
