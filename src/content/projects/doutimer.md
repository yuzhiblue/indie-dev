## 软件简介

欢迎使用直播定时助手！本软件通过调用 Windows 底层 API 接口，实现自动化点击功能。
本软件执行任务期间不要求直播伴侣一定要在最上层，您可以根据您的需求，将直播伴侣最小化，
或者放在桌面底部，均可以照常运行。

本软件运行环境要求：win10 / win11 64 位，支持本地和云电脑，不支持多开；
