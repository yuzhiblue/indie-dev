## 软件简介

欢迎使用视频号直播定时助手！本软件是直播定时助手的视频号版本。

最新版本 0.5.0，简洁稳定，欢迎试用。

通过调用 Windows 底层 API 接口，实现自动化点击功能。本软件旨在提高个人直播效率，请勿用于违法违规用途。

本软件执行任务期间不要求视频号直播伴侣一定要在最上层，您可以根据您的需求，将直播伴侣最小化，或者放在桌面底部，均可以照常运行。

小贴士：因为每个人的直播方式不同，电脑系统环境不同，电脑操作水平不同，本软件无法保证一定可以在您的电脑上正常使用，建议购买后先进行测试。

## 功能特性

- 支持直播带货
- 支持循环直播
- 支持多组定时
- 邮件通知功能
- 支持多种定时方式
