## 卖软件，你还需要一家自己的店

授权系统解决的是"怎么验证"，但独立开发者很快会撞上下一道墙——**在哪里卖**：

- 上架第三方平台，抽成动辄 20%，回款周期还长；
- 模板建站系统，功能受制于人，每年还要交服务费；
- 自己买服务器搭商城，运维成本和被攻击的风险全在自己身上；
- 想收海外用户的钱，支付接入又是一道坎。

SEdgeKey 是一套**可直接部署到 Cloudflare 的一体化全栈卡密商城系统**：同一套代码包含前端页面、SSR 渲染和后端 API，跑在 Cloudflare Workers 边缘网络上——**零成本、免运维、收款的店自己开**。

## 它在真实运营中打磨到了 v1.8.0

这不是一个半成品。SEdgeKey 当前版本 v1.8.0，经历了从单规格商品到多规格 SKU、从单一支付到 6 种支付网关、从固定内容发货到完整分销体系的持续迭代——每一步都来自真实售卖场景的反馈。

## 核心能力

### 多规格 SKU：一个商品，N 种卖法

同一个商品可以配置多个规格，**价格、成本、库存、发货方式全部按 SKU 独立设置**：

- 前台详情页提供规格选择器，价格、库存、发货提示随选中规格实时联动；
- 首页对多规格商品展示"最低在售价 起"，兼顾展示力与点击欲；
- 支持分类、上下架、有限/无限库存模式与每单限购。

卖"基础版/专业版/永久版"三档定价？一个商品搞定。

### 三种发货方式，虚拟商品全覆盖

按规格配置发货方式：

- **卡密自动发货**——下单即从库存自动分配，用户秒收货；
- **固定内容自动发货**——网盘链接、兑换说明这类统一内容，自动交付；
- **人工发货**——定制服务、实物商品，走人工处理流程。

卡密按商品规格批量导入，自动去重、批次管理、按 SKU 筛选查询，库存实时预警；高并发下单场景做了专门的索引优化，库存分配不会出错。

### 6 种支付网关，国内海外都收钱

内置支付宝（电脑网站支付/当面付）、Epay、Stripe、BEpusdt（USDT）、HashPay 六种可配置网关，另原生支持 0 元免费下单。

国内用户扫码付款、海外用户信用卡和 USDT——一家店全部承接，支付渠道的费率谈判权也在你自己手里。

### 折扣码 + 二级分销：把增长做进系统里

- **折扣码**：固定金额与百分比两种类型，下单时自动校验抵扣，促销活动随时开；
- **推广分销**：推广码追踪来源，按商品/推广员粒度配置佣金比例，**一级/二级佣金 + 一次性招募奖励**，让帮你推广的人拿到持续动力，结算管理后台统一完成。

这套分销体系意味着：你的用户、你的朋友、你的社群，都可以变成你的销售渠道——系统自动记账，不用手工对账。

### 邮件通知 + 媒体库 + 双语前台

- **邮件通知**：SMTP / API / Cloudflare Email 三种通道，订单状态变化自动触达买家，发送日志可查；
- **媒体库**：图片直传 Cloudflare KV，后台统一管理，不依赖任何第三方存储服务；
- **中英双语**：前台内置中文/英文切换，海外买家直接看英文页。

### 管理后台：安全是默认项

管理员账号体系内置 **TOTP 双重认证**、**Turnstile 登录验证码**（可选）与操作日志。默认密码登录、暴力爆破这类风险，在系统层就被挡住了。

## 和市面方案比一比

**对比传统开源发卡系统：更安全。**开源发卡系统的源码完全公开，攻击者可以直接下载代码研究漏洞——而社区项目的安全更新往往参差不齐，大量魔改二开版本更是早就没人维护，漏洞长期挂着没人修。SEdgeKey 走的是另一条路：源码不公开，攻击者没有"按图索骥"的便利；同时把 TOTP 双重认证、Turnstile 登录验证码、操作日志做成了**默认内置**的安全项——安全不依赖站长自己发现漏洞、自己打补丁。

**对比同样跑在 Cloudflare Workers 上的轻量方案：功能更完整。**Workers 生态里不少发卡小工具为了省额度，只做"单商品单价格 + 卡密发货"的最小闭环。SEdgeKey 同样零成本跑在免费额度里，但把两件真正影响"卖爆"的能力做成了标配：**多规格 SKU**（一个商品多档定价，价格/库存/发货按规格独立）和**二级分销**（一级/二级佣金 + 一次性招募奖励）。
