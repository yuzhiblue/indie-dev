## Overview

OBS Timer is a scheduled scripting plugin for OBS Studio. It controls button operations directly by calling the OBS Studio API. Simple to use, not blocked by the system, and more stable.

If you stream via OBS (on any platform — Douyin, Kuaishou, WeChat Channels, Xiaohongshu, Taobao, Bilibili, etc., as long as you can obtain the stream key, this script can control OBS to start and stop streaming), this plugin fits your live streaming scenario perfectly.

## Features

- Scheduled start streaming
- Scheduled stop streaming
- Scheduled start recording
- Scheduled stop recording
- Scheduled turn on camera
- Scheduled turn off camera
- Infinite loop supported
