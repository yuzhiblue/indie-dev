## 你的软件，还差一套放心的授权系统

独立开发者把闭源软件做出来只是第一步——**怎么卖**才是真正的难题：

- 用户买了卡密，怎么验证真伪？
- 按年收费的软件，怎么控制到期？
- 一码多用、盗刷卡密、暴力猜测，怎么防？
- 授权系统的 SaaS 服务，动辄每年几千块，还要把卡密数据放在别人手里？

License Server 就是为解决这些问题而生的一套**多软件授权码系统**：部署在你自己的 Cloudflare 账号上，**零成本运行**，数据完全归你，功能专为桌面软件的销售场景打磨。

## 它已经在真实产品里跑着

这套系统不是玩具项目。它目前承载着笔者开发的多款商业软件（直播定时助手系列）的卡密验证与激活，每天处理真实用户的授权请求，经过长期生产环境检验。

你在别的页面看到的那些工具软件——按次收费、卡密激活、到期停用——背后就是这套系统在工作。

## 核心能力

### 一套系统，管所有软件

多个软件共用一套授权系统，软件之间互相独立；还可以签发**跨软件通用的授权码**——"买 A 送 B"、"套餐捆绑销售"这类营销玩法，天生支持。

### 两种授权模式，覆盖主流卖法

- **按次授权**：1/5/10/50/100 次或自定义次数，适合按使用量计费的工具；不绑定设备，次数用完自动失效
- **按时间授权**：自定义天数或永久，一机一码，到期自动停用，适合年费订阅制

两种模式可并存，同一个系统里想怎么卖就怎么卖。

### 灵活调整：客服场景的救命功能

用户说"我买的是 30 天的想升级永久卡，或者我买的是10次的，能否送我1次"？后台直接调整——**增减次数、延长缩短时间**，已发放的授权码随时可改，不用废单重发。这个细节在真实客服中价值千金。

### 软件公告：不发版也能触达用户

按软件推送公告，客户端启动时自动拉取。临时维护、版本更新、活动通知，用户下一次打开软件就能看到——不需要用户手动检查更新。

### 安全设计：把防破解做在系统层

- **响应签名**：服务端对每个响应做 HMAC-SHA256 签名，客户端验证真伪——抓包改包、伪造"已激活"响应这类破解手段直接失效
- **三层限流**：IP 级、授权码级、激活接口级三层限流，暴力猜测卡密和批量刷激活都会被自动拦截
- **设备绑定**：时间授权一机一码，支持解绑重置，一码多机设为不可能

### 国内访问友好

针对国内网络环境做了专门优化：CORS 预检缓存、支持优选 IP 加速、客户端多域名容灾——验证请求延迟可以做到 50-80ms，用户无感。单域名被污染时自动切换备用域名，不因网络问题误伤付费用户。

## 部署有多简单

系统跑在 Cloudflare 的全球边缘网络上，不需要买服务器、不需要配数据库、不需要管证书——全部由 Cloudflare 托管。首次部署完成后，你要做的只有一件事：在管理后台批量生成授权码，拿去卖。

管理后台覆盖软件管理、公告管理、授权码的生成/查询/调整/吊销全流程，日常运营一个后台全搞定。
