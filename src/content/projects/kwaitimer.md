## 软件简介

欢迎使用快手直播定时助手！本软件是直播定时助手的快手版本。

最新版本 0.4.0328。

通过调用 Windows 底层 API 接口，实现自动化点击功能。本软件旨在提高个人直播效率，请勿用于违法违规用途。

本软件执行任务期间不要求快手直播伴侣一定要在最上层，您可以根据您的需求，将直播伴侣最小化，或者放在桌面底部，均可以照常运行。

小贴士：因为每个人的直播方式不同，电脑系统环境不同，电脑操作水平不同，本软件无法保证一定可以在您的电脑上正常使用，建议购买后先进行测试。

> 以下特性参考同系列直播定时助手（抖音 / 快手双平台）整理，具体以实际软件为准。

## 使用说明

- 调用 Windows 底层 API 实现自动化点击。
- 任务执行时，快手直播伴侣无需处于窗口最上层，可最小化或置于桌面底部。
- 已开播请勿重复开启定时开播（易异常下播）。
- 时长 / 时间模式说明：早于当前时间则延迟至次日执行。
- 购买后建议先测试，因个人环境 / 系统 / 操作水平差异，不保证所有电脑正常可用。

## 系统要求

- 操作系统：Win10 / Win11 64 位
- 支持环境：本地电脑、云电脑
- 不支持多开
- 仅限快手电脑版直播伴侣
