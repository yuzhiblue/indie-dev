## 软件简介

OBS定时助手是 OBS Studio 上面的一个定时脚本插件。通过调用 OBS Studio API 直接控制按钮操作。使用简单，不会被拦截，稳定性更高。

这个脚本的首要使用场景是定时录制功能，可以用于录课，录制会议，录制直播等场景。同时支持定时结束录制和静音自动结束录制的功能。使用起来非常方便。后期会考虑增加自动开始录制功能。

如果您使用 OBS 推流方式进行直播的话（无论是哪个平台都可以：抖音、快手、视频号、小红书、淘宝、B站等等，只要能获取到推流码就可以使用本脚本控制 OBS 开播和下播），这个插件将会非常适合您的直播场景。唯一的遗憾是没有对接推流码，需要手动输入。（不同平台获取推流码的方式不同，造成这一步开发极其困难）

## 功能特性

- 定时开始、结束：推流、录制、摄像
- 循环定时功能
- 静音自动结束：推流、录制、摄像
- 异常邮件通知功能
