## 软件简介

OBS定时助手是 OBS Studio 上面的一个定时脚本插件。通过调用 OBS Studio API 直接控制按钮操作。使用简单，不会被拦截，稳定性更高。

如果您使用 OBS 推流方式进行直播的话（无论是哪个平台都可以：抖音、快手、视频号、小红书、淘宝、B站等等，只要能获取到推流码就可以使用本脚本控制 OBS 开播和下播），这个插件将会非常适合您的直播场景。

## 功能特性

- 定时开播
- 定时下播
- 定时开启录制
- 定时关闭录制
- 定时开启摄像机
- 定时关闭摄像机
- 支持无限次循环功能
